# Menambah Informasi — Papua Field Notes

Ada tombol **+** di header dan **Catat temuan** pada setiap profil distrik.

- Pilih kabupaten, kategori, judul, ringkasan dan sumber. Sebaiknya tambahkan judul awalan `Distrik NAMA:` agar mudah difilter secara manual.
- Simpan, edit, hapus, dan ekspor JSON dari menu Panduan.
- Catatan lokal *tidak otomatis* mengubah website yang dilihat orang lain. Jangan simpan data pribadi sensitif di perangkat bersama.
- Agar catatan menjadi konten permanen: salin catatan lewat menu Panduan, kirim ke ChatGPT dan minta saya perbarui versi aplikasi. Jangan menambahkan data statistik tanpa sumber/tahun.

## Format masukan yang disarankan
Kabupaten: …
Distrik: …
Kategori: Penduduk / Kesehatan / Transportasi / Budaya / Lainnya
Informasi: …
Tahun dan sumber: …
Tanggal diperiksa: …

## Berikutnya
Ruang untuk PASTI-Papua: lokasi intervensi dan profil puskesmas/kampung, status aktivitas & catatan MEAL (perlu persetujuan konten sebelum publikasi).
